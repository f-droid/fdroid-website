### This Week in F-Droid

### TWIF curated on Friday, 07 Aug 2026, Week 32

#### F-Droid core

**[F\-Droid](https://f-droid.org/packages/org.fdroid.fdroid)** and **[F\-Droid Basic](https://f-droid.org/packages/org.fdroid.basic)** were updated to `2.0-rc0`, you know the deal, [changelog](https://gitlab.com/fdroid/fdroidclient/-/blob/2.0-rc0/CHANGELOG.md#20-rc0-2026-08-03) is short. If this is news to you and you didn't update to any 2.0 development builds yet, hello and welcome, so many things have changed, you'll just have to experience it. Navigate to the F-Droid or Basic app details page, check “Allow beta updates” in the top right three dot menu, and update.

In website news, our mirror sync permission issue should be fixed now. Do ping us if you see any package that refuses to install, after you've made sure you got the latest index update, of course.


#### Community News

**[FrOSCon 2026 Schedule](https://f-droid.org/packages/info.metadude.android.froscon.schedule)**, _Programm App für die [FrOSCon](https://froscon.org)_, was just added and make sure you install it to easily find our F-Droid contributors booth next week-end. If you already have **[Giggity](https://f-droid.org/packages/net.gaast.giggity/)** installed, you can use it with the official schedule (`https://programm.froscon.org/2026/schedule.xml`) too.

**[Rethink: DNS \+ Firewall \+ VPN](https://f-droid.org/packages/com.celzero.bravedns)** was updated to `v0.5.5z` which appears to be a bit unstable. Some users got some [crashes](https://github.com/celzero/rethink-app/issues/2946) so maybe avoid updating to this version for now. We'll disable it in our repo while the developers figure stuff out.

Missed in passed weekly news, **[Session](https://f-droid.org/packages/network.loki.messenger.fdroid/)** devs have written about ["The Future of Session"](https://getsession.org/blog/the-future-of-session) and about the ["Protocol v2 development"](https://getsession.org/blog/session-development-update-pro-beta-protocol-v2). Looks like this messenger might continue to live on...

Back in July we noticed that **[萊姆輸入法](https://f-droid.org/packages/net.toload.main.hd)** source changed some strings and autoupdate has not picked any updates... for the last 3 years. We are now up to date at `7.4.0` and we're keeping an eye on logs for any other app that might need extra attention.

We've mentioned **[Snowflake Volunteer](https://f-droid.org/packages/io.bloco.snowflake/)** at inclusion time, but did you know how this app came into existence out of [Orbot's "Kindness Mode"](https://orbot.app/kindness/)? The folks at the Tor Project host a [post](https://blog.torproject.org/snowflake-volunteer-standalone-app-to-help-people-bypass-censorship/) that explains how tools and contributors helped.
