### This Week in F-Droid

### TWIF curated on Thursday, 12 Jun 2025, Week 24

#### Community News

**[Bimba](https://f-droid.org/packages/xyz.apiote.bimba.czwek)** was updated to `3.10.0-alpha` but this was an unstable version that accidentally ended up pushed as recommended. You might encounter crashes and regressions so we ask you to skip this version _(upper right menu, "Ignore this update")_ and, if already updated, uninstall and install `3.9.0` instead.

**[CoMaps \- Hike, Bike, Drive Offline with Privacy](https://f-droid.org/packages/app.comaps.fdroid)**, _Easy map navigation \- Discover more of your journey \- Powered by the community_, is finally live. We've covered [the how](https://f-droid.org/2025/06/05/twif.html#community-news) and [the why](https://f-droid.org/2025/04/17/twif.html#community-news) already so we're not gonna tire you with context. Go install!

**[Dolphin Emulator](https://f-droid.org/packages/org.dolphinemu.dolphinemu)** was updated to `2506a`, and their [release post](https://dolphin-emu.org/blog/2025/06/04/dolphin-progress-report-release-2506/) is pretty nice to peruse even if you're not into console emulation.

**[Fedilab](https://f-droid.org/packages/fr.gouv.etalab.mastodon)** was updated to `3.33.1` adding more nice things with tags and trends. But what's more interesting is the newly included **[Fediplan](https://f-droid.org/packages/app.fedilab.fediplan)**, _Schedule your messages on Mastodon/Pleroma_.

**[Fennec F\-Droid](https://f-droid.org/packages/org.mozilla.fennec_fdroid)** was updated to `139.0.0` and we've not covered its updates for a while now. _What's new?_ Well, their changelogs are a couple of lines usually, let's list them: [135.0](https://www.mozilla.org/en-US/firefox/android/135.0/releasenotes/), [135.0.1](https://www.mozilla.org/en-US/firefox/android/135.0.1/releasenotes/), [136.0](https://www.mozilla.org/en-US/firefox/android/136.0/releasenotes/), [137.0](https://www.mozilla.org/en-US/firefox/android/137.0/releasenotes/), [138.0](https://www.mozilla.org/en-US/firefox/android/138.0/releasenotes/) and [139.0](https://www.mozilla.org/en-US/firefox/android/139.0/releasenotes/). But to be fair, we are mostly concerned about those _"Security fixes"_, right? Also interesting, since version `137.0`, F-Droid also offers the Android `x86` version too, for those two-three users out there.

_/PS: Fennec defaults to desktop mode on large screens. If you find that annoying you can disable "Always request desktop site" in Settings > Site settings, then restart the browser._

**[Godot Engine 4](https://f-droid.org/packages/org.godotengine.editor.v4)** was updated to `4.4.1.stable`, with huge changes. The [release post](https://godotengine.org/releases/4.4/) has all the gritty details, with big pictures, and the [maintenance release](https://godotengine.org/article/maintenance-release-godot-4-4-1/) polishes the experience. _Note: F-Droid builds don't have [Swappy](https://github.com/godotengine/godot-proposals/issues/2351), the Android Frame Pacing Library, included, as the library has not been added to the recipe at this moment. Help welcomed!_

**[Luanti](https://f-droid.org/packages/net.minetest.minetest)** was updated to `5.12.0` with better camera, animations, controls and [more](https://blog.luanti.org/2025/05/24/5.12.0-released/).

**[Forkgram](https://f-droid.org/packages/org.forkgram.messenger)** was updated to `11.9.2.0` bringing simple Unified Push support. The implementation only triggers the network to resume when an event is received, so the app can get them by itself. This is not like other push providers where the changed information is processed by the listener directly, but it still saves battery since the process disconnects from Telegram servers as soon as the updates are processed.
