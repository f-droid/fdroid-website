### This Week in F-Droid

### TWIF curated on Thursday, 29 May 2025, Week 22

#### F-Droid core

**[F\-Droid](https://f-droid.org/packages/org.fdroid.fdroid)** and **[F\-Droid Basic](https://f-droid.org/packages/org.fdroid.basic)** were updated to `1.23.0` entering the stable phase. We've been teasing the new fresh coat of paint in February, announced it in April with an alpha build, but now it got another round of polish on top.

What's new:

* Updated app screenshots for Material 3 (Thanks Thore!) _(Old screenshots are still hanging around subject to a swift cleaning)_
* Last material design adaptions: rounder cards
* Don't add official mirror as user mirror (Thanks Thore!)
* Fix user mirror UI bug (Thanks oldherl!)
* Respect preferred repo for counting apps in categories
* Fixed crash on started (Thanks Matthew!)

As usual we ask brave users to test this release and offer feedback _How to install this release?_ In F-Droid Client, on its own page, either scroll down, expand Versions and install the latest, or in the upper right menu choose “Allow Beta updates”. 


#### Community News

**[Aurora Store](https://f-droid.org/packages/com.aurora.store)** was updated to `4.7.1`, as unstable, but the developer asked us to disable it, as it was crashing. Next version should fix it, so wait for that.

**[Element X \- Secure Chat & Call](https://f-droid.org/packages/io.element.android.x)** was updated to `25.05.4` but only the old architecture `armv7`. The other three fail to verify reproducible caused by a tooling issue. We are investigating a workaround and we'll keep you posted.

[@shuvashish76](https://forum.f-droid.org/u/shuvashish76) dominates the news game:

**[Immich](https://f-droid.org/packages/app.alextran.immich)** was updated to `1.133.0` and its users and host-ers need to [read the release notes](https://github.com/immich-app/immich/releases/tag/v1.133.0) about the breaking changes. This is the hottest release yet for this summer, with more than 200 commits since the last version. This version brings you a new database extension, an even more optimized and faster timeline, more unified components on the web, some cool new features that have been requested for a long time, and many bug fixes and improvements.

**[Magisk](https://f-droid.org/packages/com.topjohnwu.magisk)** was updated to `29.0` bringing its Rust _composition_ [up to 40%](https://github.com/topjohnwu/Magisk/releases/tag/v29.0). Our build appears to have some issues, so better to avoid an update for now.

As the Mozilla Pocket service [will be closed soon](https://blog.mozilla.org/en/mozilla/building-whats-next/), the open web solution rise to the challenge. In no particular order:

* Wallabag devs published two posts, about [the Pocket history](https://wallabag.org/news/20250524-pocket-shutdown/) and about [how to migrate](https://www.wallabag.it/en/news/welcome-to-pocket-users). F-Droid includes the **[Wallbag client](https://f-droid.org/packages/fr.gaulupeau.apps.InThePoche/)**, the unofficial Flutter based **[Frigoligo](https://f-droid.org/packages/net.casimirlab.frigoligo/)** and the e-book reader **[KOreader](https://f-droid.org/packages/org.koreader.launcher.fdroid/)**, which has a plugin for Wallabag by default.
* Readeck devs [prepared a post](https://readeck.org/en/blog/202505-readeck-19/) too. **[Readeck App](https://f-droid.org/packages/de.readeckapp/)**, an unofficial client, was just updated to `0.4.0`.
* [Shaarli](https://shaarli.readthedocs.io/en/master/index.html#) can be hosted and we have the **[Shaarlier](https://f-droid.org/packages/com.dimtion.shaarlier/)** client ready.
* [Shiori](https://github.com/go-shiori/shiori) server is written in Go, if you ask. And the **[Shiori](https://f-droid.org/packages/com.desarrollodroide.pagekeeper/)** unofficial client is written in Java, if it matters.
* [Linkwarden](https://blog.linkwarden.app/releases/2.10) server is at version `2.10` and its unofficial companion app **[LinkDroid for Linkwarden](https://f-droid.org/packages/com.sbv.linkdroid/)** has all the modern features.
* If you host NextCloud you can use **[Nextcloud Bookmarks](https://f-droid.org/packages/org.schabi.nxbookmarks/)**.
* If you don't care about the server openness, maybe you'll use **[xBrowserSync](https://f-droid.org/packages/com.xBrowserSync.android/)** or **[PinDroid](https://f-droid.org/packages/com.pindroid/)**.
* You can go server-less, as the in-your-pocket device is better, right? For that you can use **[floccus bookmark sync](https://f-droid.org/packages/org.handmadeideas.floccus/)**, **[Linkora](https://f-droid.org/packages/com.sakethh.linkora/)** or **[LinkHub](https://f-droid.org/packages/com.amrdeveloper.linkhub/)**.
* _...or just use one of our 3000+ ToDo and Notes apps and call it a day._

The **[Prav](https://f-droid.org/packages/app.prav.client/)** devs have [answered some questions](https://mas.to/@fossunited/114563019598523620) from the FOSS United team, that _promotes and strengthens the Free and Open Source Software ecosystem in India_.
